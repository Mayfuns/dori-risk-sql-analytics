# SQL Analysis

This folder contains the complete DORI PostgreSQL risk analysis.

## Main SQL file

[Open the complete analysis](DORI%20SQL%20Analysis.sql)

The script analyses:

- Patient demographics and age-group risk
- Gender distribution
- Malignant diagnoses by body region
- Previous skin-cancer history
- Lesion growth, symptoms and biopsies
- Average lesion diameter by diagnosis
- Piped-water and sewage access
- Sanitation access versus severe diagnosis
- Smoking and alcohol behaviour
- Lifestyle combinations versus malignant outcomes

Key SQL techniques include joins, CASE expressions, grouped aggregation, `FILTER`, subqueries, `NULLIF`, `CROSS JOIN LATERAL` and percentage calculations.
